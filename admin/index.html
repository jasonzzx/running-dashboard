RUNNING / ADMIN

每周更新，只需几步

此管理面板在你的 Mac 上运行。历史数据保持不变，新活动和缺失信息会合并到本地数据库。

从 Mac 打开管理面板

在项目文件夹中双击 Start Admin.command。它会打开已登录的本地管理页面；保持终端窗口打开。

Garmin Connect

首次连接：在 Garmin 网站创建个人 API 密钥，然后粘贴到下方。密钥只保存在本机。

登录 Garmin 并创建密钥 ↗

Strava

首次连接：创建自己的 Strava API 应用，回调域填写 127.0.0.1。输入应用凭据后会前往 Strava 授权；以后无需重复登录。

打开 Strava API 设置 ↗

同步与发布

先同步，再发布。同步会自动匹配重复活动、补全缺失字段，并验证新的仪表盘快照。发布会将快照推送到 GitHub，触发 Vercel 更新。
